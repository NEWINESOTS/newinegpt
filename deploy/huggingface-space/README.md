# newineGPT (public demo)

Ask questions about the New Wine / SOTS sermon archive. Every answer cites the transcript passages it came from (message title, speaker,
date and time); click a number like **5** to read the passage.

- **Beta.** Answers can be wrong; please mark each one Good, Partly or Wrong.
- **Slow here.** This free demo runs on 2 shared processor cores: an answer takes about 1–3 minutes, one person at a time.
- **Privacy.** Your conversations are kept only in your own browser. Ratings (with the question and answer) are kept anonymously to improve newineGPT.

For a fast, private version that runs on your own computer (Windows, Mac, Linux), see **[github.com/NEWINESOTS/newinegpt](https://github.com/NEWINESOTS/newinegpt)**.
